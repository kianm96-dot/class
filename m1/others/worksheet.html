가정이란 무엇이며, 어떤 갈등이 발생할 수 있을까?

학년반번호이름

[9도02-01] 정서적, 배려적 공동체로서 가정의 특성과 도덕적 기능을 파악하고, 가정에서 발생하는 갈등을 공감적인 소통과 민주적인 과정을 통해 해소하는 의지를 기른다.

오늘의 질문가정은 나에게 어떤 곳일까?

📖요점 정리 · 교과서 개념 채우기

■ 가정의 의미와 특성 교과서 64~65쪽

(1) 가정이란 ①사회를 이루는 기본적인 단위이자 가족이 함께 어울려 살아가는 생활 공동체임.

(2) 가정은 ②이해관계로 맺어진 회사와 같은 공동체와 달리 친밀함을 바탕으로 형성된 정서적·배려적 공동체이며, 가족은 서로를 자신처럼 아끼고 사랑함.

■ 가정의 도덕적 기능 교과서 64~65쪽

(1) 가정에서 ③가족과 함께 시간을 보내고 대화를 나누는 과정에서 바람직한 삶의 태도를 배우고, 다른 사람을 대할 때 지켜야 할 예절 등을 익힘.

(2) 가정에서 배우는 삶의 태도와 예절 등을 바탕으로 바람직한 ④인격을 형성해 나갈 수 있음.

■ 가정에서 발생하는 갈등 교과서 66~67쪽

(1) 가족 내 ⑤역할 분담과 관련하여 갈등이 발생할 수 있음.

⇨ 집안일과 같이 가족 구성원이 분담해야 하는 일을 누군가 혼자 짊어져야 하면 불만이 쌓이거나 갈등이 생길 수 있음.

(2) 가족 내 가치관 ⑥차이에 따라 갈등이 발생할 수 있음.

⇨ 서로 다른 가치관과 의견을 인정하지 않고 자신의 것만 고집한다면 갈등이 생길 수 있음.

(3) 가족 내 잘못된 ⑦의사소통으로 갈등이 발생할 수 있음.

⇨ 함부로 내뱉는 말과 무례한 행동 때문에 갈등이 생길 수 있음.

⏱️1분 체크

  1. 가정은 친밀함을 바탕으로 형성된 정서적·배려적 공동체이다. ( ○ / ✕ ) ○
  2. 가정에서 가족과 함께 시간을 보내는 과정에서 바람직한 삶의 태도를 배울 수 있다. ( ○ / ✕ ) ○
  3. 가족 내 역할 분담과 관련된 갈등은 집안일과 같이 혼자 해야 하는 일을 가족 구성원이 분담할 때 발생한다. ( ○ / ✕ ) ✕
  4. 가족 내 잘못된 의사소통 때문에 가치관 차이에 따른 갈등이 발생한다. ( ○ / ✕ ) ✕

📖요점 정리 · 교과서 개념 채우기

■ 친구와 우정의 의미 교과서 80쪽

(1) 친구란 나와 오랫동안 ①친밀하게 사귄 사람을 의미함.

(2) 친구와 친밀하게 지내며 쌓은 정서적 유대감이나 정(情)을 ‘우정’이라고 함.

⇨ 우정은 상대방을 ②소중히 여기고 상대방이 잘되기를 바라는 마음을 바탕으로 이루어지며, 이러한 마음을 바탕으로 돈독해진 우정은 쉽게 변하지 않으며 우리 삶을 의미 있게 만듦.

■ 우정의 가치 교과서 81~82쪽

(1) 정서적 안정

친구와 함께 기쁨과 슬픔 등 다양한 ③감정을 나누면서 정서적 안정을 얻을 수 있음.

친구와 나누는 우정은 살아가면서 겪는 어려움을 극복하여 건강한 삶을 살아가도록 하는 버팀목이 됨.

(2) 성숙한 인격 형성

친구와 우정을 나누는 가운데 성숙한 인격을 형성할 수 있음.

④청소년기에 많은 시간을 함께 보내는 친구들과 긍정적인 영향을 주고받는다면 더 나은 모습으로 변화할 수 있음.

(3) 사회성 함양

친구와 우정을 나누며 공동체 구성원으로서 다른 사람과 더불어 살아가는 ⑤방법을 배움.

학교 안팎에서 기본적인 사회 규범 등을 익히며 ⑥사회적 ⑦존재로 성장할 수 있음.

⏱️1분 체크

  1. 친구란 나와 우연히 만나게 된 사람을 의미한다. ( ○ / ✕ ) ✕
  2. 우정은 상대방이 잘되기를 바라는 마음을 바탕으로 이루어진다. ( ○ / ✕ ) ○
  3. 친구와 우정을 나누는 가운데 성숙한 인격을 형성할 수 있다. ( ○ / ✕ ) ○
  4. 친구와 우정을 나누면 사회성을 함양하기 어렵다. ( ○ / ✕ ) ✕

오늘의 질문진짜 친구라면 어떻게 행동할까?

📖요점 정리 · 교과서 개념 채우기

■ 바람직한 친구 관계의 모습 교과서 85쪽

(1) 바람직한 친구 관계란 선한 ①성품을 바탕으로 서로를 인격적으로 존중하는 관계임.

(2) 서로를 ②인격적으로 존중할 때 바람직한 친구 관계를 맺으며 우정을 유지할 수 있음.

■ 서로 존중하는 친구 관계를 맺는 방법 교과서 86~88쪽

(1) ③차이 인정하기

① 친구 사이에는 자신의 생각을 강요하기보다는 상대방의 생각이나 가치관을 있는 그대로 인정해 주어야 함.

② 서로의 차이를 인정하고자 노력할 때 서로를 인격적으로 존중하는 ④친구 관계를 오래 유지할 수 있음.

(2) 배려하며 예의 지키기

가까운 친구 사이일수록 서로 배려하고 기본적인 예의를 지키고자 노력해야 함.
