가정에서 발생하는 갈등을 어떻게 해결할 수 있을까?

학년반번호이름
하 · 기본 개념
1하

말을 끊거나 섣불리 판단하지 않고 끝까지 듣는 공감적 소통 방법은?

  1. ①비난하기
  2. ②충고하기
  3. ③공감하며 경청하기
  4. ④비교하기
  5. ⑤무시하기
정답 ③ 역지사지의 태도로 듣는다(69쪽).
2하

민주적인 과정으로 가정 갈등을 해결하는 첫 단계는?

  1. ①대안 선택하기
  2. ②결과 받아들이기
  3. ③다수결
  4. ④어른 마음대로 정하기
  5. ⑤감정을 가라앉히고 문제를 객관적으로 확인하기
정답 ⑤ 문제 확인 → 의견 제시 및 대안 탐색 → 대안 선택 및 수용(72쪽).
3하

가족의 보이지 않는 사랑과 노력을 당연하게 여기지 않는 공감적 소통 방법은?

  1. ①감사하는 마음 표현하기
  2. ②경청하기
  3. ③비교하기
  4. ④무시하기
  5. ⑤명령하기
정답 ① 교과서 71쪽.
중 · 개념 적용
4중

“통화 소리에 잠이 깼어. 다른 곳에서 통화해 줄래?”라는 말이 “너는 생각이 없냐?”보다 바람직한 까닭은?

  1. ①상대를 비난하지 않고 존중하며 내 마음을 표현했기 때문에
  2. ②명령했기 때문에
  3. ③목소리가 작기 때문에
  4. ④짧기 때문에
  5. ⑤형이기 때문에
정답 ① 존중하며 대화하기(68·70쪽).
5중

친구와 다툰 이야기를 하는 민서에게 엄마가 말을 끊고 “네가 또 잘못했겠지.”라고 했다. 엄마에게 필요한 소통 방법은?

  1. ①공감하며 경청하기
  2. ②무시하기
  3. ③충고하기
  4. ④더 빨리 판단하기
  5. ⑤비교하기
정답 ① 섣불리 판단하지 않고 끝까지 들어야 한다(69쪽).
6중

가정 갈등을 민주적으로 해결하는 태도로 알맞지 않은 것은?

  1. ①모든 가족이 의견을 낸다
  2. ②충분히 대화하고 합의한다
  3. ③다양한 의견의 장단점을 분석한다
  4. ④결과를 받아들이고 협력한다
  5. ⑤나이가 많은 사람이 혼자 정한다
정답 ⑤ 독단과 무시를 금지한다(72쪽).
상 · 자료 해석과 추론
7상

다음 대화를 존중하며 대화하는 말로 바르게 바꾼 것은?

동생: “이 문제 너무 어려워.” 누나: “너는 이것도 못 푸니?”
  1. ①“엄마한테 물어봐.”
  2. ②“원래 못하잖아.”
  3. ③“그것도 모르면 어떡해.”
  4. ④“어려웠구나. 어느 부분이 헷갈리는지 같이 볼까?”
  5. ⑤“나한테 묻지 마.”
정답 ④ 비난 대신 공감하고 존중하는 표현을 쓴다(70쪽).
8상

다음 가족이 대청소 갈등을 민주적으로 해결하는 과정으로 가장 알맞은 것은?

아빠는 피곤하고, 언니는 시험공부로 지쳐 모두 설거지만 하겠다고 한다. 엄마는 구역을 정해 주겠다고 한다.
  1. ①엄마가 혼자 구역을 정해 무조건 따르게 한다
  2. ②각자의 사정을 듣고 여러 분담 방법의 장단점을 비교해 함께 정한다
  3. ③가장 어린 사람에게 모두 맡긴다
  4. ④가위바위보로 진 사람이 혼자 한다
  5. ⑤청소를 하지 않는다
정답 ② 문제 확인 → 의견과 대안 탐색 → 합의와 수용(72~73쪽).
9상

다음 (가)~(다)에 해당하는 민주적 갈등 해결 단계를 바르게 짝지은 것은?

(가) “잠깐 화를 가라앉히고 무엇이 문제인지 살펴보자.” (나) “각자 원하는 방법을 말해 보고 장단점을 따져 보자.” (다) “함께 정한 대로 이번 주부터 해 보자.”
  1. ①(가) 대안 선택, (나) 문제 확인, (다) 대안 탐색
  2. ②모두 대안 선택
  3. ③(가) 문제 확인, (나) 의견 제시 및 대안 탐색, (다) 대안 선택 및 수용
  4. ④모두 문제 확인
  5. ⑤(가) 대안 탐색, (나) 대안 선택, (다) 문제 확인
정답 ③ 교과서 72쪽.

10극상

공감적인 소통 방법으로 옳은 것만 <보기>에서 고른 것은?

<보기>

ㄱ. 가족의 수고에 고마움을 표현한다.

ㄴ. 상대의 말을 끝까지 듣는다.

ㄷ. 가족도 하나의 귀한 인격체로 존중한다.

ㄹ. 가족이니까 함부로 말해도 된다.

  1. ①ㄱ, ㄴ
  2. ②ㄴ, ㄷ
  3. ③ㄷ, ㄹ
  4. ④ㄱ, ㄴ, ㄷ

11극상

가정 갈등의 민주적 해결에 대한 설명으로 옳은 것만 <보기>에서 고른 것은?

<보기>

ㄱ. 충분한 대화로 합의한다.

ㄴ. 합의한 결과를 받아들이고 협력한다.

ㄷ. 한 사람의 의견만 따른다.

ㄹ. 모든 구성원이 의견을 낼 수 있다.

  1. ①ㄱ, ㄴ
  2. ②ㄱ, ㄹ
  3. ③ㄴ, ㄹ
  4. ④ㄱ, ㄴ, ㄷ
  5. ⑤ㄱ, ㄴ, ㄹ
정답 ⑤ (ㄱ, ㄴ, ㄹ) ㄷ: 독단은 민주적 과정이 아니다.
12극상

가족 사이에서 비난하는 말 한 가지를 예로 들어 공감과 존중이 담긴 말로 바꾸고, 그렇게 바꾼 말이 가정의 갈등 해결에 도움이 되는 까닭을 서술하시오.

예시 답 “너는 맨날 방을 이렇게 어지르니?”를 “방이 어질러져 있으니 물건 찾기가 힘들 것 같아. 같이 정리할까?”로 바꾸겠다. 비난하는 말은 상대를 방어적으로 만들어 다툼을 키우지만, 상대의 처지를 생각하고 함께 해결하자는 말은 상대가 존중받는다고 느껴 스스로 바꾸려는 마음을 갖게 하기 때문이다.
